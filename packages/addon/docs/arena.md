# PvP opponents (Gladius-style)

`/badb arena` opens the opponent panel. Forever has **no arenas and no rated PvP**, so there are no `arena1–5` units to track: the panel collects visible enemy players from nameplates (plus target/focus, and arena units opportunistically if a future client exposes them), showing name, class and a health bar fed by the client's percentage API — never arithmetic on secret health values.

Coverage vs Gladius is **partial**: no trinket tracking, no cooldown tracking from the combat log (unreadable on Forever), no arena frames where arenas do not exist. What it does cover — a compact, theme-consistent opponent list for battlegrounds and world PvP — replaces the common in-BG use.
