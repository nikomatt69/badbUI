How updating works

Install

  1. Quit WoW completely.
  2. Download BadbUI-1.2.2.zip above and extract it.
  3. Copy the extracted BadbUI folder into your Forever client's Interface/AddOns folder. The final path must be Interface/AddOns/BadbUI/BadbUI.toc.
  4. Optional: extract BadbUI_Guild the same way, so it sits next to BadbUI in Interface/AddOns/.
  5. Start WoW, enable BadbUI on the add-on list, log in and type /badb.
  6. First time? Run /badb setup — the guided wizard applies a per-class/role preset and walks you through the modules.
Keep your WTF folder. Your settings, profiles and module data live in WTF/ (SavedVariables), outside the add-on folder. Installing, updating or reinstalling BadbUI never requires deleting WTF — and you should not: deleting it erases your profiles and saved data.

Updating

Two ways, same rule: replace the add-on folder, keep WTF.

In-game, with the companion (recommended)

  1. Leave the desktop companion running (its watch mode, or its updates-only mode if you do not use guild sync).
  2. In game, type /reload so BadbUI reads the latest release information, then open /badb update.
  3. If a release is available, press Install update, confirm, and exit WoW completely.
  4. Wait for the confirmation in the companion window before reopening the game. The companion checks the version and SHA-256, replaces the BadbUI folder and keeps the previous one in Interface/.badbui-update-backup. Your SavedVariables in WTF are untouched.

Manually

  1. Quit WoW, download the new ZIP and delete the old Interface/AddOns/BadbUI folder.
  2. Extract the new BadbUI folder into Interface/AddOns. Do not touch WTF.
  3. Start WoW and check the version with /badb.

SHA-256 checksum

Every release ZIP is published with its SHA-256 checksum. The companion verifies version and SHA-256 automatically before installing an update, and refuses a file that does not match. For a manual download, compare the checksum printed next to the release with the file on your disk before extracting it:

  1. macOS / Linux: shasum -a 256 BadbUI-1.2.2.zip
  2. Windows: certutil -hashfile BadbUI-1.2.2.zip SHA256

If the two values differ, delete the file and download it again from this page. Only download BadbUI from this site or the project's official release page — repacked copies from other sites are not verified.

Honest limits

What BadbUI does not claim. Forever has no arenas and no rated PvP — the Arena module covers battleground and world-PvP opponents, and shows arena frames only if a future client exposes them. Add-ons cannot read your GPU, CPU or RAM: SystemProfile works from display resolution, measured frame rate and the client's own graphics settings. Quest coverage is partial: the quest journal, objectives and tracker are covered, while a full quest database and extra map markers (what Questie ships as data) are not — BadbUI states per-module coverage on its Suite page instead of pretending otherwise. Add-ons also cannot read the combat log on Forever, so combat tools use the client's native APIs and degrade gracefully where an API is unavailable.
