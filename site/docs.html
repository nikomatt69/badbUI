Getting started

From download to a configured interface in about five minutes. BadbUI is a single addon folder — no libraries to install separately, no in-game dependencies.

Install

  1. Download and extract. Unzip the release so the folder lands in <Forever client>/Interface/AddOns/BadbUI/. The file Interface/AddOns/BadbUI/BadbUI.toc must exist at exactly that path — if you see a doubled BadbUI/BadbUI/ folder, move the inner one up.
  2. Check the client. BadbUI 1.2.1 targets interface 16001 (Forever 1.60.x). In game you can confirm your build with /dump select(4, GetBuildInfo()). A different interface number means the client will mark the addon out of date.
  3. Log in and enable. On the character screen open AddOns and tick BadbUI. First login opens the setup wizard automatically after a few seconds — or start it any time with /badb setup.
  4. Open the control panel. Type /badb. Everything — modules, profiles, macros, guides, updates — lives in this one window. The same panel is also listed under the game's native Options → AddOns → BadbUI.
  5. Arrange your frames. Type /badb unlock to drag unit frames, the quest tracker, meters and monitors into place, then /badb unlock again to lock. Positions are saved per profile.
  6. Save your settings. BadbUI stores settings in SavedVariables, which WoW only writes on /reload, logout or a clean exit. After big changes, type /reload so nothing is lost in a crash.

The two commands to remember: /badb opens everything, and /reload saves and refreshes the UI. Every other command on this page is a shortcut into the same panel.

First-run wizard

The wizard (/badb setup) walks through role confirmation, a class preset, content choices and integrations, then applies everything with a backup taken first — so /badb undo can roll the whole thing back. New characters on an account that already finished the wizard get a short version: reuse an existing profile or create a new one. Full details are in Profiles, presets & wizard.

Updating from a previous version

Replace the BadbUI folder with the new one and /reload. Your settings survive — they live in WTF, not in the addon folder. If you run the companion, in-game updates are even easier: see Updates via companion.

Bags

Replaces Baganator / Syndicator — partially

A single searchable inventory for bags and bank across all your characters. Open it with /badb bags or from Game → Inventory in the panel. Search ignores case and accents, accepts several words or an item ID, and groups stacks of the same item variant into one row showing character, source and total count. Hover any row for the real item tooltip; shift-click inserts the item link into an open chat.

  • /badb bags <text> — opens the Bags view with the search pre-filled.
  • /badb bags bank — opens the Bank view. Visit a banker once so BadbUI can capture your personal bank; afterwards the last capture is shown anywhere.
  • Moving and using items still happens in the client's own bag windows — BadbUI is the finder, not a replacement bag frame. The normal bag key opens the client bags as usual.
  • BadbUI keeps bag and bank snapshots for the last 24 characters, discards captures older than 90 days, and keeps the archive when you switch profiles.

Suite coverage is honest: unified search and viewing replace the common Baganator/Syndicator use, but custom categories, sorting rules, quick transfers, mail, equipped gear and the guild bank are not covered. See Suite.

Auction

Replaces Auctionator — partially

Talk to an auctioneer, type /badb auction and search by item name. Each Search press sends one request within the client's rate limits and shows the lowest price the client reports, quantity and variants where available. Save a term with Save search and recall it from the menu; menu selections never fire requests on their own.

  • History keeps one observation per day per market and variant, per realm, faction and auctioneer location, for up to 21 days. Select an item to compare its observed minimums over time.
  • An optional tooltip line (Game → Auction House → Last observed price) shows the latest observation with place and date, for variant-free commodities, out of combat.
  • Buys and listings always go through Blizzard's native controls — BadbUI helps you pick the price, then you confirm in the standard window.
  • The archive holds up to 500 market/variant combinations and 24 saved searches, shared across profiles.

Coverage vs Auctionator is partial: name search, saved terms, observed-minimum history and the commodity tooltip are in; full scans, structured shopping lists, transaction history, selling automation and profession integration are not. In-game guide: /badb guide open auction:market.

Combat

Replaces Details! — partially

A damage and healing meter plus a threat view, built entirely on the client's native C_DamageMeter and threat APIs. Open it with /badb combat, optionally auto-open on login, and drag it by its header or with /badb unlock. Position and size follow your profile.

  • Report tab — pick a metric and an encounter: current fight, session total, or up to 30 recent encounters. Select a row to see the spell breakdown when the client exposes a public spell ID.
  • Threat tab — /badb combat threat with a hostile target selected. Percentages show the aggro threshold at each participant's range; ordering uses raw threat where available, then aggro status.
  • When the client marks values as secret (Forever inherits Midnight-style restrictions), the panel passes them only to the permitted display functions and says so, instead of guessing. Combat data is in-memory only; with the panel closed, no readings happen.

Coverage vs Details!, Details! Tiny Threat and ThreatClassic2 is partial: history depth is whatever the client provides, and there is no cross-player comparison export, persistent logging, streamer panels or Details! plugins. Threat is limited to your target and the APIs the client offers.

Encounters

Replaces BigWigs / Capping — partially

Boss timelines, battleground queues, instance visits and lockouts in one themed window. Open it with /badb encounters; it remembers its position per profile and can auto-open at boss pull.

TabCommandWhat it shows
Boss/badb encounters bossCountdown and status of native encounter-timeline events
Battlegrounds/badb encounters pvpTime waited, average wait, invite expiry and match duration
Visits/badb encounters visitsRecent instance entries on this account, with character and boss outcome
Lockouts/badb encounters lockoutsResets and progress of the current character's active lockouts

Timers come from C_EncounterTimeline; if the client hides an ability name, it is only passed to the allowed display function while bars and ordering use public durations. The visit log keeps up to 120 visits from the last 90 days per account. Coverage vs BigWigs, Capping and Nova Instance Tracker is partial — per-boss custom alerts, PvP objective timers, win prediction and log sharing are out of scope.

World

Replaces TomTom — partially

Save waypoints, follow one on screen, and pin it on the native map. Open the window with /badb waypoint, save your current position, import the pin already on your map, or type a map ID with coordinates from 0 to 100.

  • /badb waypoint 35.7 42.5 My spot — saves a waypoint in your current zone in one line.
  • Follow shows destination and straight-line distance when both positions are on the same map and the client exposes its scale. The monitor moves with /badb unlock and can be hidden per profile.
  • Pin on map uses WoW's single personal waypoint; Restore waypoint puts back the pin BadbUI replaced, and disabling the module restores it too (out of combat).
  • Up to 100 waypoints per account; the active destination is session-only.

Coverage vs TomTom is partial: saved waypoints, coordinates, same-map distance and the native pin are in; the guidance arrow, routes and minimap pins are not. Map changes (Leatrix Maps, Atlas), gathering nodes (GatherMate2) and rare alerts (RareScanner) stay outside this module.

Quests & Quest Tracker

Covers Questie — partially

A searchable quest journal plus a pinned-quest monitor. Open it with /badb quests (same command for the tracker), search by title, zone or ID, open a row to read its objectives, and pin it with Highlight. The Ready to turn in filter uses the quest log's own state, History shows recent turn-ins and the XP the client reported, and the footer tracks progress on your current level.

  • Quest Tracker (the journal's monitor option, also /badb questtracker) shows up to five pinned quests with the next readable objective or turn-in state. Newly accepted quests can be auto-watched. The title reopens the journal; /badb unlock moves the monitor.
  • History starts when you enable the module: up to 25 pinned quests and 50 turn-ins for each of the last 24 characters, shared across that character's profiles. Turned-in or removed quests leave the pinned list automatically.
  • For story text, rewards and objective areas use the WoW quest log and map — native markers depend on your client settings. If the log becomes unreadable, BadbUI keeps the last reading in memory and marks it as such.

Coverage vs Questie is partial. BadbUI covers the journal, objectives, turn-in filter and active-quest monitor. It has no quest database of its own, so there are no extra map markers for quests you have not picked up, no objective spawn locations and no party sharing of quest data. Guided routes and levelling paths (the Polestar-style use) are likewise not included — your data packs and dedicated guide addons keep their job. See Honest limits.

Loot

Replaces Pawn — partially

Compare items with your own stat weights and keep a wishlist of drops. Open it with /badb loot — optionally /badb loot <item ID> to compare straight away. In the Compare tab, paste an item ID or link; add a second reference of the same equipment type to compare two items directly.

  • Stat weights live in your profile and start at zero for every stat — nothing is scored until you say what you value. The score is simply each client-reported stat multiplied by its weight, summed.
  • Loot favourites holds up to 100 personal targets shared across profiles. Observed loot remembers the last 240 item/zone combinations for 90 days when the client exposes loot contents; recording can be turned off per profile.
  • Optional scored and favourite tooltips appear out of combat only.

Coverage vs Pawn, AtlasLootClassic and AtlasBIStooltips is partial: effects, sockets, weapon DPS, automatic upgrade suggestions, drop percentages, precompiled loot sources and best-in-slot lists are not calculated or stored. In-game guide: /badb guide open loot:confronto.

QoL

Replaces Leatrix Plus — partially

Small automations, each switched on individually and stored per profile. Open the page with /badb qol (Game → Quality of life). Holding Shift suspends automation for the current interaction.

  • Auto-loot uses WoW's native preference. BadbUI restores the previous value when you turn the toggle off, disable the module, or switch to a profile that leaves the preference to the client.
  • Auto-repair makes one attempt per merchant visit, with personal gold only, when the cost is within your profile's cap and your balance covers it.
  • Sell junk needs a confirmation from the QoL page at an open merchant and uses the client's own junk classification. If your bags or the merchant change, you confirm again after checking the new count.
  • Quest dialogs can auto-accept and auto-complete from an open NPC dialog. Item quests, automatic offers, shared quests, turn-ins costing money or currency, and reward choices always stay manual.

Coverage of Leatrix Plus is partial: loot, personal repairs, confirmed native junk selling and simple dialogs are in; guild funds, custom sell exclusions, flight automation and more remain unimplemented. In-game guide: /badb guide open qol:automation.

System Profile

/badb system classifies the machine you are playing on and prints the result — for example System: balanced (1920×1080, 60 FPS). /badb system apply (or the options page) applies the matching graphics tier, and Restore puts back the exact values you had before.

  • Tiers: performance (under 30 FPS, or very high pixel count with low FPS), balanced (up to 1080p), quality (1440p at 55+ FPS), ultra (4K at 55+ FPS).
  • Each tier suggests a UI scale (see /badb scale in the command table) and a small set of candidate graphics CVars — shadow quality, particle density, view distance. CVars that do not exist on the Forever client are skipped and reported as none.
  • Detection uses only legal signals: physical display resolution (GetPhysicalScreenSize) and measured frame rate (GetFramerate, sampled on world entry, never per frame). The same rules apply on macOS, Windows and Linux because they depend on the client, not the OS.

Why no hardware names? An addon cannot read your GPU model, CPU, RAM or operating system — WoW exposes none of those to addons, and BadbUI does not pretend otherwise. The tier is an honest estimate from resolution and measured FPS, nothing more. See Honest limits.

Arena

Covers Gladius — partially

/badb arena opens a compact, Gladius-style opponent panel: name, class and a health bar for each visible enemy player. Because Forever has no arena1–5 units to track, the panel collects opponents from nameplates, plus your target and focus — and arena units opportunistically, if a future client ever exposes them. Health bars are fed by the client's percentage API, never by arithmetic on secret health values.

Forever has no arenas and no rated PvP. There is no arena queue, no rating and no arena opponents to frame. This module exists for battlegrounds (Warsong Gulch 10v10, Arathi Basin and Darkspear Islands 15v15, Alterac Valley 40v40) and world PvP, which is where a Gladius-style list is actually useful on this client. If you came looking for arena frames, that feature cannot exist on Forever — for anyone's addon, not just ours.

Coverage vs Gladius is partial: the opponent list for battlegrounds and world PvP is covered; trinket tracking, cooldown tracking from the combat log (unreadable by addons on Forever) and arena frames are not, because the underlying data does not exist here.

Professions

/badb prof shows the current character's profession ranks and the cooldowns you chose to track. It contains no recipe database and no invented spell lists — only what the client reports and what you add yourself.

  • /badb prof or /badb prof list — reads ranks via the client's profession APIs and saves a snapshot per character (up to 50 characters, 12 professions each). The snapshot refreshes on login, on skill changes and on logout; /badb prof refresh forces a re-read. If the API is missing, the page says professions are unavailable on this client instead of guessing.
  • /badb prof add <spell ID>, /badb prof remove <ID>, /badb prof clear — track up to 20 cooldowns of your choice. BadbUI shows the remaining time or Ready, read live from the client.
  • No daily or weekly cooldown is ever inferred: Forever exposes no verified legal API that lists profession cooldowns, so BadbUI invents none.

The Suite declares no replacement for this module: ranks plus hand-picked cooldowns are at most a partial answer to tradeskill addons, and recipes, materials, crafting queues and auto-learned cooldowns are missing — so no coverage claim is made until an honest mapping exists.

Macros

6,609 entries

Ready-made macros for every class and each of its three talent trees, split into PvE and PvP, plus general macros that work for everyone. Open the catalogue with /badb macro or via Macros in the panel. Entries are available to choose from — BadbUI never creates macros automatically, because the game's macro slots are limited and yours.

  • /badb macro — browse by class, tree and PvE/PvP filter. Turn on an entry and it appears in the game's /macro panel; turn off deletes it. Subcommands: list, on, off, show, alloff, or a macro name.
  • 6,609 entries in total, including 244 general macros. Per class: Warrior 480, Paladin 1,072, Hunter 428, Rogue 457, Priest 1,183, Shaman 644, Mage 444, Warlock 612, Druid 1,045. Everything in the catalogue — names, descriptions, spell names, notes — is in English.
  • Fixed-unit variants expand targeted spells into single-purpose macros: Foc (focus), MO (mouseover), Me (yourself), TT/FT (target's/focus's target), P1–P4 (party), P1T–P4T, R1–R40 (raid, PvE), B1–B5 (bosses, PvE), B1T–B5T, and A1–A5 arena-enemy compatibility templates (PvP). Fixed-unit macros never switch your target and have no fallback unit. Friendly casts require a living friendly unit; interrupts include /stopcasting.
  • Disabling the Macros module does not delete macros you already placed on your bars.

Arena macro entries are compatibility templates. Forever currently has no arenas, so the A1–A5 entries are labelled as such and only work on an arena-enabled client. For teammates, use the partyN variants, not arenaN. Raid indices follow the current roster — they do not permanently identify a player, tank or healer — and boss indices depend on encounter frames the client may not expose.

Guides

Offline, searchable guides bundled inside the addon — they work with no network, no companion and no account. Almost every module registers its own guide, so the answer to “how does this work?” is usually one command away, in game.

  • /badb guide — opens the guide browser. /badb guide open <id> jumps straight to a guide (IDs appear throughout this page, e.g. /badb guide open auction:market).
  • /badb guide search <text> — full-text search across all bundled guides; results print in chat with their IDs.
  • /badb guide bookmarks — your bookmarked guides for quick return.

Guides are versioned content shipped with the addon, so they always match the BadbUI version you run. They describe what the module does on the Forever client — including, where relevant, what still needs verifying in the real client.

Suite

Suite answers one question: “which of my installed addons does BadbUI already cover?” Each BadbUI module declares what it replaces; Suite cross-references those declarations with the addons actually installed and reports, per addon, the covering module and whether coverage is full (the addon can go) or partial (the common use is covered; the module text says what is missing).

  • /badb suite — lists every installed addon BadbUI covers, with its module and coverage. Addons not installed are not listed.
  • /badb suite disable — disables the fully covered addons for you. Nothing is deleted from disk; removing the folder from Interface/AddOns afterwards is your call. A /reload applies the change.
  • Conflicts are surfaced, not hidden: for example, X-Perl replaces unit frames, so /badb doctor warns if it runs alongside BadbUI's UnitFrames — use /badb disable UnitFrames if you prefer X-Perl.

The module sections above carry the per-addon verdicts (Baganator, Auctionator, Details!, BigWigs, TomTom, Questie, Gladius, Pawn, Leatrix Plus and more) — always with the same rule: partial means partial, and the missing pieces are named.

Backups

Named snapshots of your entire BadbUI configuration — profiles, module options and layout — that you can restore in one command. BadbUI also takes automatic pre-preset backups before the wizard or a preset changes things, which is what makes /badb undo safe.

CommandWhat it does
/badb backup create [label]Creates a snapshot, optionally labelled
/badb backup listLists snapshots with their IDs and numbers
/badb backup restore <id|n>Restores a snapshot; in combat the restore is deferred until combat ends
/badb backup delete <id|n>Deletes a snapshot you no longer need

Backups live in BadbUI's saved data, so they survive addon updates. They are configuration only — they do not back up the game itself, your macros on the action bars, or other addons' settings.
