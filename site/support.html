Support

BadbUI is free

World of Warcraft add-ons must be distributed free of charge under Blizzard's add-on policy — so BadbUI is free, in full. There is no paid version, no premium unlock and no feature behind a donation. Every module, macro, guide and update on the download page is available to everyone.

Report a bug

The fastest way to get a bug fixed is a report the maintainer can act on. BadbUI builds most of it for you, in game:

  1. Reproduce the problem, then type /badb doctor run — BadbUI checks module state and known conflicts and prints a summary.
  2. Type /badb doctor report and copy the text it shows. The report contains add-on and client versions, module states and recent errors — it is scrubbed of personal data.
  3. Recent Lua errors only: /badb doctor errors lists what BadbUI captured, with occurrence counts.
  4. Open an issue on the project's GitHub repository (Issues tab) and paste the report, plus: what you did, what you expected, what happened instead, and your BadbUI version (/badb shows it).
Before reporting: update to the latest release on the download page, disable other interface add-ons once to check for a conflict, and try /reload. If the error only happens with another add-on enabled, name that add-on in the issue — BadbUI's Suite page lists which add-ons its modules replace, and running both at once is the most common source of conflicts.

Get help in game first

In-game

/badb

One panel for every module. Search any setting, check the Suite page for exactly which installed add-ons each module replaces, and read the offline manual and guides — they work with no connection at all.

Setup

/badb setup

The guided wizard re-applies a per-class/role preset and walks through bags, auction, combat, encounters, world, quests, loot and QoL. Safe to re-run: your profiles live in WTF and are not erased.

Diagnostics

/badb doctor

/badb doctor run for checks, /badb doctor report for a copyable report, /badb doctor errors for captured Lua errors. Attach the report to any GitHub issue.

Questions

Is BadbUI really free? Yes — completely. Blizzard's policy requires WoW add-ons to be free of charge, so there is no paid tier and nothing is held back. Tips on this page are voluntary thank-yous only.
Does tipping unlock anything? No. No feature, module, macro, guide or update is tied to a tip, and support does not depend on one either.
Where do I report a bug? In game run /badb doctor report, copy the text, and open an issue on the project's GitHub repository with the report and your steps to reproduce. See Report a bug above.
An update broke my layout. Now what? Your settings live in WTF and survive updates. Re-run /badb setup to re-apply a preset, or restore a configuration backup from inside BadbUI. If the companion installed the update, the previous add-on folder is kept in Interface/.badbui-update-backup.
Does BadbUI work without the companion and BadbUI_Guild? Yes. Both are optional: BadbUI_Guild only adds guild calendar/roster sync for guilds that use it, and the companion only syncs guild data and installs updates you confirm with /badb update. Manual ZIP updates work fine.
