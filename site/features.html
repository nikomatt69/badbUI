BadbUI 1.2.1 · WoW Forever · Interface 16001

One addon.
Every system covered.

BadbUI replaces the pile of single-purpose add-ons with one coherent, Polestar-inspired panel — midnight navy, warm amber, 1px hairlines — for bags, auction, combat, encounters, world, quests, loot and quality of life. Everything below runs offline, in English, inside the Forever client.

Modules

Fourteen modules, one design system

Open /badb and search any setting. Each module can be toggled independently; the Suite page states exactly what it replaces — fully, partly, or not at all.

Inventory

Bags

/badb · Bags

Unified bag view with live search, category grouping, item-level display and bank/reagent views. Replaces the default bags without hiding what Forever's API cannot expose.

Economy

Auction

/badb · Auction

Auction House helpers: price history from your own scans, undercut checks and posting guides. No fabricated market data — prices come from scans you run on your realm.

Meters

Combat

/badb · Combat

Native-API combat readouts, cooldown tracking and unit-frame auras. Forever hides secret values and blocks combat-log parsing, so BadbUI degrades gracefully instead of guessing.

PvE

Encounters

/badb · Encounters

Boss guides and native encounter-timeline support for dungeons (5), Barrow Deeps (10), Hyjal Summit (20) and Onyxia's Lair (40). Offline guides for every launch encounter.

Open world

World

/badb · World

Waypoints, minimap tools and zone helpers for leveling, gathering and world PvP across Azeroth. Battleground templates cover Warsong Gulch, Arathi Basin, Alterac Valley and Darkspear Islands.

Questing

Quests + QuestTracker

/badb · Quests

Quest log, tracker and step-by-step guides that work fully offline. Coverage is partial versus Questie — BadbUI says so in the Suite page rather than implying a complete database.

Loot

Loot

/badb · Loot

Loot scoring, upgrade comparisons and roll helpers based on the gear your client actually reports. No invented item database; unknown items are labelled unknown.

Comfort

QoL

/badb · QoL

Small comforts in one place: auto-repair prompts, vendor grays, chat tweaks, tooltip extras and frame unlocking via Edit Mode layouts captured into profiles.

Performance

SystemProfile

/badb system

Classifies your machine from legal signals — display resolution, sampled FPS and existing graphics CVars — into Performance, Balanced, Quality or Ultra, then suggests a UI scale. /badb system apply applies it; restore returns your original values.

PvP opponents

Arena

/badb arena

A Gladius-style opponent panel for battlegrounds and world PvP, built from nameplates plus target/focus. Forever has no arenas, so there are no arena1–5 frames — see Honest Limits below.

Tradeskills

Professions

/badb prof

Per-character profession ranks and the cooldowns you choose to track (/badb prof add <spell ID>). No invented recipes, materials or automatically learned cooldowns.

Coverage

Suite

/badb · Management → Addons replaced

The honesty page: for every installed add-on, whether a BadbUI module fully replaces it, partly replaces it, or does not replace it. Check it before deleting anything.

Updating

Updates

/badb update

Checks the official catalogue via the desktop companion, verifies version and SHA-256, and installs only after you confirm in-game and quit WoW. Your previous folder is kept as a backup; SavedVariables in WTF/ are untouched.

Setup

Presets & Wizard

/badb setup

Guided first-run wizard with 54 per-class/role presets across Solo/Leveling, Dungeon (5), Raid 10/20/40 and Battleground layouts. When role detection is uncertain, the wizard asks you to confirm.

Automation

Macros — 6,000+

/badb · Macros

More than 6,000 macro variants organised by class, spec and situation, plus an in-game editor. Macros use only secure actions the Forever client allows.

Knowledge

Guides & Backups

/badb · Guides / Backups

Offline English manual and module guides, profile import/export, and one-click backups of your BadbUI settings so an update or a new PC never costs you your layout.

    Honest limits

    What BadbUI cannot do on Forever

    Stated plainly, before you install

    Forever has no arenas. There is no rated PvP and no arena1–5 unit at launch, so the Arena module is an opponent panel for battlegrounds and world PvP — partial coverage versus Gladius, with no trinket or combat-log cooldown tracking.

    Add-ons cannot read your GPU. WoW exposes no GPU model, CPU, RAM or OS to add-ons. SystemProfile uses display resolution, sampled frame rate and existing graphics CVars only, and skips CVars that do not exist on this client.

    Questie coverage is partial. BadbUI's offline quest guides do not claim Questie's full database. The Suite page (/badb → Management → Addons replaced) grades every replacement claim so you can decide what to uninstall.

    Combat data is restricted. Health and threat can be secret values and the combat log is not readable by add-ons on Forever. BadbUI uses native percentage APIs and never does arithmetic on secret values.
