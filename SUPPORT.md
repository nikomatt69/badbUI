# Support BadbUI

BadbUI is free. World of Warcraft add-ons must be distributed free of charge, so there is no paid version, no premium unlock, and no feature behind a donation.

If BadbUI saves you time and you want to say thanks, you can send a voluntary tip:

- **Revolut (fiat, any amount):** https://revolut.me/REPLACE_WITH_YOUR_HANDLE
- **Crypto:** send only to the address below, on the exact network shown. Sending on the wrong network can lose the funds permanently.
  - Token: `REPLACE_WITH_TOKEN` (for example USDT)
  - Network: `REPLACE_WITH_NETWORK` (for example TRON / TRC20)
  - Address: `REPLACE_WITH_PUBLIC_WALLET_ADDRESS`

Replace the placeholders above with your public Revolut handle and public wallet address before publishing. Never publish a seed phrase, private key, Revolut password, or exchange API key — only a public receive address/link.

Tips are voluntary, are not a purchase, and do not unlock anything in-game.
